# Illustration de remplacement Studio

`developer-workshop.webp` : 960×540, générée avec l’outil intégré ImageGen puis optimisée en WebP.

Prompt : atelier fictif de développeurs geek, écrans de création de jeux, claviers, casque, livres et croquis, détails steampunk discrets en cuivre/laiton, éclairage ambre et cyan, illustration détaillée sans marque ni studio réel.

Utilisation : `SteampunkStudioPlaceholder`, uniquement en l’absence de visuel disponible. Ce décor générique ne représente pas les locaux réels d’un studio et ne remplace aucune image officielle en base.
